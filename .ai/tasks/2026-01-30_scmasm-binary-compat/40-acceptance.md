BYTE1   .DA $42
BYTE2   .DA $FF
*
* Multiple bytes
BYTES   .DA $01,$02,$03,$04,$05

* Words (16-bit values, little-endian, use .HS)

HEXDATA .HS 0A0B0C0D0E

### Expected Binary Output

**Golden reference (28 bytes):**
```
00000000: 4200 ff00 0100 0200 0300 0400 0500 3412  B.............4.
00000010: cdab c8c5 cccc cf0a 0b0c 0d0e            ............
```

**Breakdown:**
- `0x42 0x00` - BYTE1 ($42) + padding
- `0xFF 0x00` - BYTE2 ($FF) + padding
- `0x01 0x00 0x02 0x00 0x03 0x00 0x04 0x00 0x05 0x00` - BYTES array (5 bytes with padding)
- `0x34 0x12` - WORD1 (little-endian)
- `0xCD 0xAB` - WORD2 (little-endian)
- `0xC8 0xC5 0xCC 0xCC 0xCF` - TEXT "HELLO" (high-bit ASCII)
- `0x0A 0x0B 0x0C 0x0D 0x0E` - HEXDATA (raw hex bytes)
