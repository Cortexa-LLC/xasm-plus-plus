## Task Description

Implement Phase 3.3: Output format plugins for xasm++ assembler - listing files (.lst) and symbol tables (.sym).

### Background and Context

Phase 3.1 (CLI) and Phase 3.2 (File I/O) are complete. The assembler can read source files and write binary output. However, developers need additional output formats for debugging and documentation:
- **Listing files** (.lst) - Show addresses, bytes, and source side-by-side
- **Symbol tables** (.sym) - Show all symbols with their final addresses

These formats are standard across assemblers (ca65, Merlin, etc.) and essential for debugging.

### Desired State

## Technical Approach

### Design Decisions

**Output Format Conventions:**

**Listing File Format (.lst):**
```
LINE  ADDR  BYTES             SOURCE
----  ----  -----             ------
0001  1000                    ; Example program
0002  1000  A9 42             LDA #$42
0003  1002  85 00             STA $00
0004  1004  60                RTS
```

**Symbol Table Format (.sym):**
```
Symbol Table:
NAME        ADDRESS   TYPE
----        -------   ----
START       $1000     Label
DATA        $2000     Label
BUFFER      $0080     Label
```

**Implementation Strategy:**
- Create `ListingOutputPlugin` class
- Create `SymbolOutputPlugin` class
- Both inherit from `OutputPlugin` interface
- Integrate with CLI arguments (`--list`, `--symbols`)
- Format output with proper alignment

### Implementation Plan

1. **Create ListingOutputPlugin**
   - Implement `GenerateListing()` method
   - Format: line number, address, bytes, source
   - Handle lines with no bytes (comments, labels)
   - Proper column alignment

2. **Create SymbolOutputPlugin**
   - Implement `GenerateSymbolTable()` method
   - Extract symbols from assembler symbol table
   - Sort alphabetically
   - Format with proper alignment

3. **Update main.cpp**
   - Call listing plugin if `--list` specified
   - Call symbol plugin if `--symbols` specified
   - Handle write errors

4. **Add output format tests**
   - Test listing generation
   - Test symbol table generation
   - Test format correctness
   - Test error handling
